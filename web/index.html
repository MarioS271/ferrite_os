FerriteOS

A bare-metal x86-64 hobby OS in Rust, booted via Limine in your browser through QEMU compiled to WebAssembly.

Start demo Source on GitHub Download ISO

What you're about to run

  • QEMU qemu-system-x86_64 compiled to WebAssembly (from ktock/qemu-wasm).
  • EDK2 OVMF firmware (x86_64) loaded as -bios.
  • Limine v8.x bootloader chainloading the FerriteOS kernel ELF off a UEFI El Torito ISO.
  • Serial output only — the wasm binary has no graphical display support, so the kernel framebuffer is not rendered. The terminal shows COM1 serial output.

Heads-up

First load fetches ~45 MB of WebAssembly + firmware + the kernel ISO.
The page uses a service worker to enable SharedArrayBuffer (COOP/COEP),
so if you see a "needs reload" notice on first visit, refresh once.

Hosted on GitHub Pages. WebAssembly QEMU is Apache-2.0. coi-serviceworker is MIT.
